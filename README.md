					Overview

	This program analyzes structural variations between equivalent molecules (same number of atoms and same 
	atom numbering) using .txt files generated by Gaussian 16, where distances, valence angles, and dihedral 
	angles have been printed via the keyword:

		"geom=(cangle,cdistance,dihedral)"

	The program:
		-Automatically extracts the distance matrix, valence angles, and dihedral angles.
		-Saves the extracted values to text files.
		-Computes RMSD for distances, valence angles, dihedrals, and a total RMSD relative to a reference
		 molecule.
		-Generates an Excel file with the RMSD results.

				Requirements

	-Python 3.8+ (tested with recent versions).
	Python libraries:
		-numpy

				Input file requirements

	Files must be plain text (.txt) from Gaussian.
	They must contain the sections:
		-Distance matrix (angstroms):
		-Interatomic angles:
		-Dihedral angles:

	All molecules must have the same number of atoms and be numbered identically.
	For optimized structures, distances and angles must be computed with a single-point calculation at the 
	end of the optimization.

				How to use
	1- Run the script:
		 _______________________________________________________
		|							|
		|	      python your_script_name.py	    	|
		|_______________________________________________________|

	2- Welcome message:
		A brief explanation is displayed. Press any key to continue.

	3- Set an identification:
		You will be asked for an identification name, used in the output filenames.

	4- Load molecules
		-A file dialog opens to select one or more .txt files.
		-You may load additional molecules if desired.

	5- Select the output directory
		Choose the folder where results will be saved.

	6- Processing
		For each file, the program extracts and saves:
			Distance matrix: distancias-matrix-<filename>.txt
			Full values: valores<identification>.txt

	7- Select the reference molecule
		A numbered list of loaded molecules is shown. Enter the number of the reference molecule.

	8- RMSD analysis
		An interactive menu is displayed:
			1 – RMSD of distances
			2 – RMSD of valence angles
			3 – RMSD of dihedral angles
			4 – Total RMSD (mean of available RMSDs)

		Results are printed to the console and saved to:
			resultados<identification>.txt
			rmsd_results_<identification>.xlsx

	9- Repeat analysis
		You can run multiple analyses on the same set of molecules.

	10- Exit
		You can either analyze other molecules or close the program.

				Generated files
  _____________________________________________________________________________________________________________
    File								                          Contents   
    distancias-matrix-<filename>.txt	   	 Distance matrix with atom header (number and symbol).  
    valores<identification>.txt		    	   Distances, valence angles, and dihedrals for all molecules.
    resultados<identification>.txt		  	 Detailed results of the computed RMSDs.
    rmsd_results_<identification>.xlsx	   Summary table with RMSD for distances, angles, dihedrals, and total.
  _____________________________________________________________________________________________________________

				Notes
	Label standardization:
		-For valence angles, the outer atoms are sorted alphabetically to avoid duplicates due to symmetry.
		-For dihedral angles, the absolute value is used and either the forward or reverse representation 
		is chosen based on the alphabetical order of the first and last atom.

	Missing angles: if a molecule lacks an angle present in the reference, it is reported and excluded from 
		the RMSD calculation.

	Total RMSD: computed as the mean of the available RMSDs (distances, valence, dihedrals). Categories with 
		no common values are skipped.

	Key assumption: molecules must be structurally equivalent (same atom numbering). Otherwise, RMSDs may not 
		be physically meaningful.
